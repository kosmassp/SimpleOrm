# amend-cases — `diff --amend` (ADR-0017 addendum 3)

Each case lays out a migrations directory **as data**, runs `diff` (amend or plain)
against the fixed fixture, and pins what happened to the tree. No database.

**The fixture** (every implementation defines it natively): table `amend_widgets`
with model `id INTEGER key generated, name TEXT not null, remark TEXT null`;
migration versions `V0001` (one table step, creates the table) and `V0002` (one
table step, added `note`) in one namespace. `"fixture": "none"` means a namespace
with no versions at all.

```json
{ "name": "…", "comment": "…",
  "files": [ { "path": "V0002", "generated": true, "dialect": "sqlite" },
             { "path": "Table/AmendWidget/V0002_AddNote", "generated": false } ],
  "snapshots": [ { "path": "Table/AmendWidget/V0001.schema.json", "snapshot": { "…snapshot document…": "" } } ],
  "command": { "amend": true, "force": false, "name": "AddRemark", "dialect": "sqlite", "applied": false },
  "expect": { "exit": 0,
              "deleted": [ "…" ], "written": [ "…" ], "kept": [ "…" ],
              "files": [ { "path": "…", "contains": [ "…" ], "omits": [ "…" ] } ],
              "output": [ "…" ], "error": [ "…" ] } }
```

- **Source paths carry no extension** (`V0002`, `Table/AmendWidget/V0002_AddNote`):
  each implementation appends its own (`.cs`, `.php`, …) when laying out and
  checking the tree. Snapshot paths are literal (`V0001.schema.json`). This is what
  keeps one case runnable by every port (ADR-0026 — the PHP port exposed it).
- `files`: what exists before the run. `generated: true` means the file carries the
  generator's ownership header (`Generated by simpleorm diff`); a root may also
  carry a dialect stamp. `generated: false` is a hand-written file.
- `snapshots`: snapshot documents (format v2, as in `snapshot-cases/`) at their paths.
- `command.applied`: whether the given database reports the target version as
  applied (the `--db` probe) — it only ever warns.
- `expect`: exit code; paths that must be gone, must exist, must still exist;
  content fragments a written file must contain/omit — **language-neutral tokens
  only** (column names, storage types, step class names, the generator header),
  never call syntax; substrings of the output and of the error. Messages may
  differ per language; what they name may not.
